📐 Formula Reference with Examples

Sample rates: Direct 5% · Levels 10 / 6 / 4 / 3 / 2 / 1% · Depth 6. Change any rate in Chain Commission tab — same formulas apply.

1 Direct Referral Bonus (Sponsor Bonus)

Used on: Chain Commission · Self-Sale (referral only)
direct_bonus = package_price × direct_rate
  • package_price new member যে package কিনেছে তার দাম
  • direct_rate admin-set % (sample 5%)
  • Trigger: শুধু নতুন referral — self-purchase-এ চলে না
  • Destination: Sponsor E-Wallet · category “Direct bonus”
Example: Rima buys Pack ₹500, direct rate 5%.
direct_bonus = 500 × 5% = ₹25
Sponsor INF00123-এর wallet-এ ₹25। যদি Rima নিজেই upgrade করে (self) → bonus = ₹0।
Spec: Table 14, Table 15, MEM-01

2 Level (Generation) Commission

Used on: Chain Commission · Tree View (monthly)
level_commission(i) = base_amount × level_rate[i] // i = 1 … depth_ceiling (sample depth = 6)
  • base_amount package price (বা EMI, যদি renewal commission on)
  • level_rate sample: L1=10%, L2=6%, L3=4%, L4=3%, L5=2%, L6=1%
  • Placement tree ধরে উপরে যায় — sponsor tree নয়
Example: Sale ₹1,500 (September volume).
L1 = 1500 × 10% = ₹150
L2 = 1500 × 6% = ₹90
L3 = 1500 × 4% = ₹60
L4 = 1500 × 3% = ₹45
L5 = 1500 × 2% = ₹30
L6 = 1500 × 1% = ₹15
Level subtotal = ₹390 · + Direct 5% (₹75) → total commission ₹465 (31%)।
Spec: Chapter 5.2–5.3, Table 16, CMP-01

3 Reserved Position Routing

Used on: Chain / Tree — amber RCS nodes
if level[i].is_reserved: Company_Reserved_Pool += level_commission(i) // tag: position_id else: upline.E_Wallet += level_commission(i)
  • Reserved = company blank seat (Level 1–2 sample) — owner নেই, কিন্তু tree-তে আছে
  • Pool amount position ID-তে জমা থাকে
Sale options when ID sold: A — new owner earns only from sale date (pool stays with You) B — full accrued pool → new owner wallet C — pool × release_percent → new owner
Example: Sale ₹1,500 · L3 & L4 reserved.
L3 pool = 1500 × 4% = ₹60
L4 pool = 1500 × 3% = ₹45
Your pool total = ₹105
Live members get ₹360 · You (company) hold ₹105 in Reserved Pool।
Spec: Chapter 4.5, Table 11, RSV-04, RSV-05

4 Self-Purchase / Upgrade

Used on: Self-Sale tab
direct_bonus = 0 member.PV += package_PV × qty level_commission(i) = package_total × level_rate[i] // still paid to upline
  • Self-buy = নিজের ID-তে package — নতুন sponsor relationship নেই
  • PV rank qualification-এ কাজে লাগে
Example A — Referral: Pack ₹500, rate 5% → Sponsor gets ₹25 + levels on ₹500.
Example B — Self: Same pack ₹500 → Sponsor gets ₹0 · Member gets +150 PV · Upline still gets level commissions on ₹500.
Spec: Section 6.2, Table 14

5 Insurance EMI Amount

Used on: Insurance EMI · Self-Sale insurance block
emi_amount = premium ÷ emi_count
  • premium full term premium (e.g. ₹12,000 / year)
  • emi_count instalments (e.g. 12 months)
Example: Family Protect FP12 · premium ₹12,000 · 12 months.
emi = 12000 ÷ 12 = ₹1,000 / month
Life Secure ₹24,000 / 24 mo → EMI = ₹1,000 / month same amount, longer term.
Spec: Section 7.2, 7.3, INS-12

6 EMI Reserve & Withdrawable Balance

EMI Wallet · Payout check
emi_reserve = emi_amount // locked from reserve_days before due (sample 7 days) withdrawable_bal = wallet_balance − emi_reserve − other_locks
  • Due date-এর ৭ দিন আগে থেকে EMI amount withdraw করা যায় না
  • Short balance → status Due → next commission credit-এ sweep
Example: Wallet ₹2,500 · EMI due ₹1,000 · reserve on.
withdrawable = 2500 − 1000 = ₹1,500
Member max payout request = ₹1,500 (not ₹2,500)।
Spec: Table 28 INS-06, INS-07, INS-09

7 Monthly Wallet Movement

EMI simulation table
closing = opening + commission_in − emi_out − payout_out // order: credit first, then EMI, then payout
Example — one month:
Opening = ₹2,500
+ Commission = ₹3,400
− EMI = ₹1,000
− Payout = ₹2,000
Closing = 2500 + 3400 − 1000 − 2000 = ₹2,900
Spec: Table 30 (six-month worked example)

8 Payout Net Amount

Payout workflow
payout_request ≤ withdrawable_balance net_payout = payout_request − fee − tax
Example: Request ₹2,000 · fee 1% · tax 0%.
fee = 2000 × 1% = ₹20
net = 2000 − 20 = ₹1,980
Wallet থেকে ₹2,000 lock → bank-এ ₹1,980।
Spec: Table 43, Table 44, PAY-01, PAY-02

9 Wallet Ledger Running Balance

Wallet Ledger tab
balance[t] = balance[t-1] + amount[t] // append-only — mistake = new reversal row, never edit old row
Example:
Start 0
+ Direct bonus +25 → bal 25
+ Level commission +90 → bal 115
− EMI −1000 → (if enough) else Due
− Payout −50 → bal decreases
Screen-এর balance সবসময় ledger-এর sum।
Spec: Section 8.2, WAL-01

10 Plan Payout Ratio

Chain Commission total row · admin plan check
total_rate = direct_rate + Σ level_rate[i] // sample: 5 + 10+6+4+3+2+1 = 31%
Example: Package ₹300 · total rate 31%.
total_commission = 300 × 31% = ₹93
অর্থাৎ প্রতি ₹100 sale-এ ₹31 commission বেরোয় (live + pool + unallocated)। Admin plan change-এর আগে এই ratio দেখে।
Spec: Section 5.2, CMP-08

11 Monthly commission cycle (wallet timing)

Tree View month selector
this_month_commission → status = PENDING (visible on tree) next_month_1st → previous month amounts hit E-Wallet past_month → status = PAID (already in wallet)
Example:
September sales volume ₹1,500 → commission ₹465 = PENDING on tree
October 1 → ₹465 credited to wallets (live + pool rules)
August was ₹2,800 volume → ₹868 already PAID in September
Spec: payment cycle configurable (instant / daily / monthly) — demo uses monthly

12 Rank qualification & progress

Ranks & Rewards tab
rank_ok = (PPV ≥ need) AND (directs ≥ need) AND (team ≥ need) AND (GPV ≥ need) progress% = min(100, current / required × 100) remaining = max(0, required − current)
Example — next rank Silver (need: PPV 150, Directs 5, Team 50, GPV 5,000).
Member now: PPV 120, Directs 4, Team 28, GPV 3,200.
PPV 120/150 = 80% · 30 baki
Directs 4/5 = 80% · 1 baki
Team 28/50 = 56% · 22 baki
GPV 3200/5000 = 64% · 1,800 baki
Overall ≈ average of four % · Bronze already achieved if criteria met · reward unlocks on rank complete.
Spec: Table 17, Section 5.4, 9.10

13 Self-business retail income

Self-Sale — own retail volume
retail_income = retail_volume × retail_rate // this is member’s own income — NOT network commission
Example: Member sells products/services ₹8,000 this month · rate 10%.
retail_income = 8000 × 10% = ₹800
Network commission আলাদা (direct + levels + insurance) · retail নিজের business margin।
Spec: commercial / self-business (demo extension of member earnings)
